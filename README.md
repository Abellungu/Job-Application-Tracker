# Job Application Tracker

## About the Project

The Job Application Tracker is a web application that helps users
keep track of their job applications in one place.

## Features

- Add a new job application
- Record the company name and position
- Select an application status
- Search applications
- Filter applications by status
- View application statistics
- Save applications using localStorage

## Application Statuses

- Applied
- Interested
- Interview
- Rejected
- Offers

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- JSON

## How to Use

1. Enter the company name.
2. Enter the position.
3. Select the application status.
4. Click *Add Application*.
5. Use the search and filtering features to manage applications.
